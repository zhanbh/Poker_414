# 414 微信小游戏

这是独立的 414 微信小游戏工程，与 `minigame/`（麻将）、`miniprogram/` 和 H5 分开。它使用 Canvas 和 `compileType: game`，可单独导入微信开发者工具；房间状态、规则校验和实时通信仍由仓库现有服务端处理。

## 导入与配置

1. 在微信开发者工具中导入本目录 `minigame-414/`，不要导入仓库根目录或麻将的 `minigame/`。
2. `project.config.json` 已配置 414 专用小游戏 AppID；请勿改成体验者 AppID，也不要直接复用麻将 AppID。
3. 将这个小游戏 AppID 关联到 CloudBase 环境 `prod-d0gncxity070cbe6f`，并按 [CloudBase 环境共享文档](https://docs.cloudbase.net/run/develop/access/mini) 配置授权，允许此小游戏访问云托管服务 `express-xgjy`。环境共享需要在相应小程序/小游戏管理后台配置授权。
4. `src/config.js` 默认连接 `/414-ws`；若小游戏云托管 WebSocket 不可用，将回退至 `wss://308.company/414-ws`。回退方案需在小游戏后台配置合法 socket 域名，并确保 TLS 证书和链路在目标设备可用。
5. 当前使用同一邀请码配置、同一 Node 服务进程和 `414` 房间；麻将使用不同的 `gameId`/房间，因此两种游戏状态在服务端分开。

## 当前客户端范围

- 竖屏邀请码/昵称入口，进入房间后请求横屏，退出时恢复竖屏；
- 414 大厅、四个座位、房主开局；
- 首牌权、选牌出牌、差牌、不要、炸弹响应、结算后准备下一局；服务端负责规则校验；
- 房间文字聊天、对玩家发送互动、房主移除玩家；
- 断线后尝试恢复原会话。

此工程是拆分后的首个可运行版本。导入、CloudBase AppID 授权、横屏 API 和真机网络仍需在微信开发者工具中验证；上传体验版前需确认合法域名配置。
