# 414 微信小程序内测端

这是与网页版/H5 并行的原生微信小程序前端。它复用同一套 Node.js 房间服务和共享协议，通过 `wx.cloud.connectContainer` 连接 CloudBase 云托管的 `/414-ws` WebSocket 服务。

## 当前页面

- 入口：选择 414 或麻将，分别保存会话；退出房间后回到入口并释放当前身份。德州扑克代码暂时保留，但已从小程序入口和页面路由中移除。
- 414：四人私房扑克牌、观战位、上帝视角、房主移除、断线提示、重连和结算。
- 麻将：四人大众麻将基础玩法。

小程序端只负责展示和发送命令，牌型、牌力、升级、下注和结算仍由服务端最终裁决。

## 导入开发者工具

1. 使用微信开发者工具导入本目录 `miniprogram`。
2. 将 `project.config.json` 中的 appid 占位值替换为自己的 AppID。
3. `utils/config.js` 中配置了 CloudBase 环境 ID `prod-d0gncxity070cbe6f`、云托管服务 `express-xgjy` 和 WebSocket 路径 `/414-ws`；如控制台中的实际值不同，请同步修改。
4. `app.js` 会初始化对应的 CloudBase 环境。请确认该环境已关联当前小程序 AppID，云托管服务正常运行且 WebSocket 路由可用。
5. 小程序端连接使用 CloudBase SDK，不再读取 `414.serverOrigin`，也不需要为这条 CloudRun WebSocket 连接配置自有域名白名单。登录后每 25 秒发送一次活动心跳，避免 CloudRun 空闲连接超时。H5 仍使用原有独立连接方式。

小程序和 H5 使用同一个服务端房间状态；小程序当前开放的玩法会话 token 分别保存为 `414.sessionToken` / `mahjong.sessionToken`。德州扑克实现仍在仓库中，但 H5 和小程序内测入口当前均不可选德州扑克。

## 内测方式

小程序没有与 H5 `?test=1` 相同的 URL 测试开关。开发阶段可在微信开发者工具中点击“预览”进行真机内测；邀请其他测试者时，上传体验版并在微信公众平台将对方添加为体验成员。此项目仍是邀请码进入的内测版本。
