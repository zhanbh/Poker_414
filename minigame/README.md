# 414 麻将微信小游戏

这是一个独立的微信小游戏客户端，不覆盖 `miniprogram/`、H5 或网页端。客户端用 `game.js` 启动，在 Canvas 上绘制入口、大厅、麻将牌桌和房间聊天；登录、座位、发牌、规则校验与结算继续复用现有 Node.js 服务端和 `/414-ws` 协议。

## 在微信开发者工具中导入

1. 导入仓库中的 `minigame/` 目录，不要导入仓库根目录或 `miniprogram/`。
2. 检查 `project.config.json`：`compileType` 应为 `game`，`appid` 应与已经开通小游戏的 AppID 一致。
3. `game.json` 默认启动方向为竖屏，登录入口使用竖屏布局；成功加入麻将房间后会调用 `wx.setDeviceOrientation` 切换到横屏，退出后切回竖屏。该方向 API 从基础库 2.26.0 起支持，本项目配置基础库 3.8.8；切换后会重新设置 Canvas 尺寸并重绘。工具顶部应进入“小游戏”模式，并从 `game.js` 启动 Canvas 客户端。
4. `src/config.js` 默认连接 CloudBase 环境 `prod-d0gncxity070cbe6f`、云托管服务 `express-xgjy` 和 `/414-ws`。先在开发者工具中确认小游戏 AppID 已关联该 CloudBase 环境。
5. 客户端在运行时优先尝试 `wx.cloud.connectContainer`；如果当前小游戏基础库不提供此接口，会回退到 `wss://308.company/414-ws`。使用回退时，需在微信公众平台小游戏设置中将 `308.company` 配置为合法 socket 域名，且 ECS 证书和 WSS 链路需能被目标设备接受。

不要为了让开发者工具通过而关闭域名校验后直接上传体验版；上传和真机测试前要使用已备案、可用的正式域名及合法域名配置。若 CloudBase 的小游戏 SDK/运行时不支持云托管 WebSocket，备用 WSS 域名是必须的连接方案；服务器目前不会为小游戏自动部署客户端代码，上传版本仍需在开发者工具中执行。

## 当前功能

- 启动时展示拟真资源加载进度（随机 2~3 秒平滑加载动画与阶段 Tips）；
- 高质感国风茶馆背景与 Canvas 动态悬浮金粉浮尘粒子动效；
- 典雅国潮风房间入口卡片（输入邀请码即可进入，自动同步微信身份与头像）；
- 四个麻将座位支持展示玩家微信圆形头像、大厅开局、牌河和本人手牌；
- 出牌、听牌、吃碰杠、胡牌和过等由服务端提供的可用操作；
- 房间文字聊天、对玩家投递番茄/泼水/比心/亲吻互动；
- 观战者查看牌桌并参与聊天和互动；
- 退出房间并释放当前座位，切回竖屏并继续保持动态背景。

## 本地验证

在仓库根目录运行：

~~~powershell
npm test -- --run
npm run build
~~~

这些命令验证客户端模型、Canvas 命中区域和现有服务端构建。小游戏模拟器/真机仍需在微信开发者工具中单独验证，特别是 CloudBase WebSocket 接口是否对当前小游戏运行时开放以及小游戏后台的 socket 域名配置。
