# 414 私房内测

这是一个面向 4 位受邀玩家的桌面浏览器实时扑克游戏。当前实现使用单个 Node.js 进程、内存房间和固定全局邀请码，适合小规模内测，不是面向公众的账号系统。

## 本地运行

需要 Node.js 22 或更高版本。

```powershell
npm install
$env:INVITE_CODE = "inner-414"
npm run dev:server
```

另开一个终端启动 Vite 页面：

```powershell
npm run dev
```

打开 `http://localhost:5173`，四位玩家输入同一个邀请码和不同昵称。第一个入房玩家是房主；四人到齐后房主可以开始游戏。

### 单机四人测试模式

如果只用一个 Chrome 测试四名玩家，打开 `http://localhost:5173/?test=1`。在 4 个标签页中分别打开这个地址并使用不同昵称登录；测试模式会为每个标签页使用独立的玩家会话。首次切换测试模式前建议重启服务，以清空当前内存房间。

生产式单进程验证：

```powershell
$env:INVITE_CODE = "inner-414"
npm run build
npm start
```

健康检查地址为 `/health`，只返回进程可用性和房间是否占用。

## 内测流程

- 固定座位为 A/B/C/D，A、C 一队，B、D 一队。
- 首局发牌后从随机候选开始逐人选择“立棍”或“跳过”；全部跳过才正常开打，立棍后先给队友抢立，再只向对方展示反立；后续牌局继承上一手第一名的首牌权。
- 页面只向本人发送私密手牌，其他玩家只看到昵称、队伍、剩余牌数、公开出的牌、牌权和“爆”标识；当前牌权会在对应头像的圆形边框上顺时针流动高亮。
- 本手主显示在左上角，AC/BD等级以侧边挂件显示；牌权只通过头像圆形边框提示。有人可出差牌时取消普通牌权特效。
- 本局结束后会显示中文结算弹窗；关闭弹窗即自动准备，四人全部准备后自动进入下一局并重新发牌，结算期间可查看其他玩家剩余手牌。
- 不设自动倒计时或自动过牌。连续 1 分钟无用户动作会显示“暂离”，下一次有效用户操作会清除标识。
- 房主可以在大厅移除玩家或结束房间；进行中的本手不能重开。服务重启会丢失内存房间。

完整牌型和升级规则见 [docs/rule-reference.md](docs/rule-reference.md)，互联网验收步骤见 [e2e-scenarios.md](e2e-scenarios.md)。

## 已知限制

当前是受控内测版本：单房间、无数据库、无账号体系、无机器人、无聊天和无历史记录。普通 HTTP 会明文传输固定邀请码，只适合邀请码不公开的内测环境；如果扩大范围，应先切换 HTTPS、轮换凭据并重新设计身份系统。
