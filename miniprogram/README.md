# 414 微信小程序内测端

这是与网页版/H5 并行的原生微信小程序前端。它复用同一套 Node.js 房间服务和共享协议，使用原生 `wx.connectSocket` 连接 `/414-ws`。

## 当前页面

- 入口：选择 414 或德州扑克，分别保存会话；退出房间后回到入口并释放当前身份。
- 414：四人私房扑克牌、观战位、上帝视角、房主移除、断线提示、重连和结算。
- 德州扑克：两人以上即可开局；满座或牌局进行中后加入的人进入观战/等待席，下一局自动入座；支持公共牌、下注滑杆、弃牌、过牌、跟注、加注、All-in、结算和退出。

小程序端只负责展示和发送命令，牌型、牌力、升级、下注和结算仍由服务端最终裁决。

## 导入开发者工具

1. 使用微信开发者工具导入本目录 `miniprogram`。
2. 将 `project.config.json` 中的 appid 占位值替换为自己的 AppID。
3. 本地开发时，默认服务地址是 `http://localhost:3000`；开发者工具中可按需关闭域名校验。
4. 真机或发布前，将服务地址写入本地存储键 `414.serverOrigin`，例如 `https://414.example.com`；服务端必须提供 HTTPS/WSS。
5. 在微信后台将服务域名加入合法 socket 域名。

小程序和 H5 使用同一个服务端房间状态，但会话 token 按玩法分别保存为 `414.sessionToken` / `texas.sessionToken`。如果退出后重新选择玩法，传输层会重新建立 WebSocket 连接并带上新的 `gameId`。
