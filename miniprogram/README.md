# 414 微信小程序内测端

这是与电脑网页版并行的原生微信小程序前端。它复用现有 Node.js 房间服务和共享牌局规则，网页版仍然使用 client 目录和 Socket.IO；小程序使用原生 wx.connectSocket 连接 /414-ws。

## 导入开发者工具

1. 使用微信开发者工具导入本目录 miniprogram。
2. 将 project.config.json 中的 appid 占位值替换为自己的 AppID。
3. 本地开发时，默认服务地址是 http://localhost:3000；微信开发者工具中可按需关闭域名校验。
4. 真机或发布前，将服务地址写入本地存储键 414.serverOrigin，例如 https://414.example.com；服务端必须提供 HTTPS/WSS。
5. 在微信后台将服务域名加入合法 socket 域名。

## 当前页面

- 登录：固定邀请码、昵称、会话恢复。
- 大厅：AC/BD 座位、房主开始、房主移除玩家。
- 对局：主牌和等级、公开出牌、手牌选择、出牌/过牌/差牌、立棍/反立、爆牌、结算和重连。

小程序端只负责展示和发送命令，牌型、牌力、升级和结算仍由服务端最终裁决。原生触摸拖动排序和完整视觉优化将在通信链路稳定后继续完善。
